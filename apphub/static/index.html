Dove conservare le applicazioni?

Puoi cambiare modalità in qualsiasi momento. Il passaggio non elimina le app o i dati dal PC.

La repository deve esistere già ed essere accessibile a Git su questo PC. Le modifiche fatte qui verranno pubblicate con un commit sulla repository privata.
